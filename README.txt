[최우영수산 주문계산기 - 배포 안내]

이번 압축폴더에는 파일이 여러 개 들어있습니다.
(전에는 index.html 하나였는데, 홈 화면 설치가 제대로 되도록
아이콘과 설치 설정 파일을 별도 파일로 분리했습니다.)

포함된 파일
- index.html          → 앱 본체
- manifest.json        → 앱 이름/아이콘 설정 (홈 화면 설치용)
- sw.js                → 서비스워커 (앱 설치가 되려면 반드시 필요)
- icon-192.png          → 앱 아이콘 (작은 사이즈)
- icon-512.png          → 앱 아이콘 (큰 사이즈)
- apple-touch-icon.png  → 아이폰 홈 화면 아이콘
- favicon.png           → 브라우저 탭 아이콘

★ 중요: 이 7개 파일을 전부 GitHub 저장소의 "같은 폴더(루트)"에
함께 업로드해야 합니다. index.html만 올리면 아이콘과 설치 기능이 동작하지 않습니다.

1. GitHub 업로드 방법
   - 저장소를 열고 "Add file" > "Upload files"
   - 이 7개 파일을 전부 한 번에 끌어다 놓고 Commit
   - (기존에 index.html 등 같은 이름 파일이 있으면 덮어씁니다)

2. Vercel 배포
   - Vercel에서 해당 GitHub 저장소를 Import (이미 연결되어 있으면 자동 재배포됨)

3. 앱 설치 (홈 화면 아이콘)
   - 배포된 주소로 폰에서 접속
   - 화면 하단 "📲 홈 화면에 앱 설치하기" 버튼 클릭
   - 안드로이드: 최우영수산 결제 아이콘으로 홈 화면에 설치됨
   - 아이폰(사파리): 공유 버튼 > "홈 화면에 추가"로 설치
   - 설치가 바로 안 보이면 새로고침 한 번 하고 다시 접속해보세요
     (서비스워커가 처음 등록되는 데 잠깐 걸릴 수 있습니다)
